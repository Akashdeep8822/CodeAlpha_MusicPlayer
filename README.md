# CodeAlpha_MusicPlayer

A cassette-deck themed music player built with **HTML, CSS, and JavaScript** as part of the CodeAlpha Frontend Development Internship.

## 🎵 Features
- Play, pause, next, and previous track controls
- Displays song title and artist
- Draggable progress bar with live current time / duration
- Volume control slider
- Playlist with clickable tracks and an active-track indicator
- Animated spinning cassette reels while a track plays
- Auto-advances to the next track when one ends

## 🛠 Built With
- HTML5 (`<audio>` element)
- CSS3 (gradients, keyframe animations)
- Vanilla JavaScript (no frameworks/libraries)

## 🚀 How to Run
1. Clone this repository
2. Open `index.html` in any browser
3. An internet connection is needed since the demo tracks are streamed from [SoundHelix](https://www.soundhelix.com), a free sample-audio source

To use your own songs, edit the `tracks` array in the `<script>` section of `index.html` and point each `src` to your own audio file.
